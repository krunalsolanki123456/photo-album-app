# Flipora PDF Export — Landscape Spread Match

Updated: 2026-09-15

- `Print / Save PDF` now exports one **two-page photobook spread per PDF page**.
- The PDF uses the same left/right page composition shown in Preview.
- PDF orientation/page size follows the selected album leaf size. For the default 12 × 36 album, the PDF page is **36 × 12 inches (landscape)**.
- Other supported album sizes derive their PDF spread size from the selected leaf dimensions.
- Editor/viewer UI is excluded from PDF: no arrows, header, page dots, sound controls, or trial notice bar.
- Trial-plan watermark remains on the album pages, matching Preview rules.
- Page artwork, photos, text, scrapbook elements, backgrounds, and facing-page order are reused from the Preview renderer.

Browser note: in the system print dialog choose **Save as PDF**. CSS requests the album's landscape page size automatically; do not manually force Portrait.
